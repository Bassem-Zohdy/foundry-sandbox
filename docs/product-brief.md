# foundry-sandbox: Product Brief

Sandbox test content for trying Foundry on GitHub.

A small status page for an internal API. Support staff open the dashboard to see whether the API is up before they escalate a customer ticket. Today they ask an engineer on chat, which takes minutes and interrupts the engineer.

- Users: support staff (about 20), on-call engineers.
- Problem: no self-service way to see API health.
- Idea: an API health endpoint plus a dashboard that shows its status.
